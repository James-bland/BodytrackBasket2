How We Determine Sequence Correctness

A basketball free throw is a proximal-to-distal kinematic chain. HoopSense segments each attempt into 5 stages and verifies 5 biomechanical rules:
  1. 1. Stance → 2. Prep Dip (PP): Coincident knee, hip, and ankle flexion with the ball lowered into the shooting pocket (tdip < trelease).
  2. 3. Power Rise (Proximal Lead): Lower-body extension (knee/hip peak velocity) initiates before peak elbow extension (Δtlegs→elbow ∈ [20, 260] ms).
  3. Controlled Sub-Maximal Knee Push: Smooth knee extension matching NCAA proficient velocity (≤ 260 °/s) rather than an abrupt jump.
  4. 4. Release (RP) Alignment: Near-vertical trunk (−1.1° ± 3.5°), high release (≥ 1.12× height), and full elbow extension (~160°–166°).
  5. 5. Follow-Through Hold: Wrist flexion ("gooseneck") held above the shoulder for ≥ 200 ms after release.

Key NCAA Scientific Insights

  • Controlled Knee Velocity (p = 0.005, d = 1.04): Proficient shooters extend their knees more smoothly (212.9 ± 47.6 °/s peak) than non-proficient shooters (269.4 ± 60.6 °/s).
  • Vertical Trunk at Release (p = 0.016, d = 0.88): Proficient shooters keep a near-vertical torso (−1.11 ± 3.49°), whereas non-proficient shooters lean forward (+1.87 ± 3.28°).
  • Higher Release Point (p = 0.010, d = 0.44): Proficient shooters release at 1.17 ± 0.05× stature vs 1.12 ± 0.07× — without over-jumping (excessive release height >1.19× led to misses).
  • Consistent Release Angles: Elbow at release ~160° (166° in made shots), knee ~166°, hip ~174°, release angle ~51.5°.
